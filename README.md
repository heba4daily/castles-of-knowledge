# قلاع المعرفة — موقعك الخاص

هذا المجلد هو اللعبة مع السيرفر اللي يربط اللاعبين. لما ترفعه على استضافة، يصير عندك رابط عادي ترسله لأي أحد، يفتحه من أي متصفح ويلعب معك بدون تسجيل دخول.

## محتويات المجلد

- `public/index.html`: صفحة اللعبة.
- `server.js`: السيرفر اللي يفتح الغرف ويربطكم ببعض.
- `package.json`: معلومات تشغيل السيرفر.

## الخطوة ١: ارفع الملفات على GitHub

1. سوّ حساب مجاني في https://github.com
2. اضغط زر **+** فوق يمين الصفحة، واختر **New repository**.
3. اكتب الاسم: `castles-of-knowledge`، وخلّه **Public**، واضغط **Create repository**.
4. في الصفحة اللي تطلع، اضغط على رابط **uploading an existing file**.
5. افتح مجلد `castles-online` على جهازك، وحدد اللي بداخله (`public` و `server.js` و `package.json` و `README.md`) واسحبهم كلهم لصفحة GitHub.
   - تأكد إن مجلد `public` انرفع وفيه `index.html`.
6. اضغط **Commit changes**.

## الخطوة ٢: شغّل الموقع على Render

1. ادخل https://render.com واضغط **Get Started**، وسجّل دخول بحساب GitHub نفسه.
2. اضغط **New +** واختر **Web Service**.
3. اختر المستودع `castles-of-knowledge` واضغط **Connect**.
4. عبّي الإعدادات كذا:
   - **Language**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. اضغط **Create Web Service** وانتظر كم دقيقة لين تشوف كلمة **Live**.
6. فوق بتلقى رابط موقعك، شكله كذا: `https://castles-of-knowledge.onrender.com`

## الخطوة ٣: العب

1. افتح الرابط، اكتب اسمك، واضغط **أنشئ غرفة**.
2. ارسل الرابط والرمز لصاحبك. يفتح الرابط، يكتب اسمه، ويدخل الرمز.
3. ابدأ المعركة!

## ملاحظات

- **أول فتحة بطيئة:** الاستضافة المجانية تنام لو ما أحد فتح الموقع ١٥ دقيقة. أول ما تفتحه ياخذ تقريباً دقيقة يصحى، بعدها يشتغل عادي.
- **التعديل:** لو عدّلت اللعبة، ارفع `public/index.html` الجديد على GitHub بنفس الطريقة (اسحبه داخل مجلد `public` واضغط Commit)، و Render يحدّث الموقع لحاله خلال دقائق.
